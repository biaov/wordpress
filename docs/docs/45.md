# 使用 Windows 自带的 VHDX + BitLocker 加密学习资料

## 前言

- 有时候我们需要加密学习资料，防止被他人访问；但当文件较大时，压缩和解压会很耗时
- 又不想安装第三方软件的话，可以用 Windows 专业版自带的 `VHDX + BitLocker` 来加密，全程无需额外工具
- 小提示：BitLocker 仅在 Windows 专业版 / 企业版 / 教育版可用，家庭版不支持
- 至于学习资料为什么需要加密……懂的都懂，这里就不展开了😏

## 第一步：创建 VHD/VHDX 文件

- 使用快捷键 `Win + R` 打开运行对话框，输入 `diskmgmt.msc`，打开磁盘管理工具
- 点击菜单栏的 `操作`，选择 `创建 VHD`
  - 小提示：如果 `创建 VHD` 是置灰状态，先点击下方磁盘列表的空白区域，再点击 `创建 VHD` 即可

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/189bc95268e14ef5a2edff187be5d843.png#pic_center)

- 填写信息后，点击 `确定`：
  - **位置**：选择存放路径（`.vhdx` 文件由系统自动创建，无需手动新建），例如 `D:\Mine\VHDX\学习资料.vhdx`（建议起个正经点的名字，比如 `考研真题` 或 `系统备份`，别人一看还以为你是个卷王）
  - **虚拟硬盘大小**：按需填写，例如我的学习资料需要 `10TB`，一般 `10GB` 就够用了
  - **虚拟硬盘格式**：选择 `VHDX` 格式（需与前面文件名的后缀保持一致）
  - **虚拟硬盘类型**：
    - 动态扩展：创建快，占用空间随内容逐步增长（**推荐**，快就完了，还勤俭持家，用多少占多少）
    - 固定大小：创建慢，一次性占满全部设定容量，读写更稳定

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/bf0cbed8692547f2af4eba015a54401a.png#pic_center)

## 第三步：启用 BitLocker 加密

- 打开资源管理器，右击新加的简单卷，选择 `启用 BitLocker`

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/4d067f84655b471fa416e49c302a187b.png#pic_center)

- 选择 `使用密码解锁驱动器`，并将恢复密钥 `保存到文件`，之后一路点击 `下一步` 即可
- 小提示：密码别设成 `123456` 或生日，也别设成连你自己都记不住的神仙密码——不然到时候锁住的就不是别人，而是你自己了🤡
- 小提示：保存的恢复密钥文件，如果别人获取到了，就可以解密驱动器中的数据。如果你的密码保证不会忘，就可以删除这个文件，避免被他人利用。

## 使用方法

到这里就成功了，你可以通过密码解锁这个驱动器。日常使用方式如下：

- **禁止别人看**：把它当作 U 盘使用，右击该卷选择 `弹出`，别人就看不到了（弹出即隐身，家人共用电脑的救星）
- **自己看**：双击之前的 `学习资料.vhdx` 文件，输入密码即可挂载（每次输密码，都是一次神圣的仪式感）
- **彻底删除**：弹出之后，直接删除 `学习资料.vhdx` 文件即可（注意：删除后数据无法恢复，一键毁尸灭迹，不留后患）

## 总结

- 以上就是利用 Windows 专业版自带的 `VHDX + BitLocker` 加密学习资料的完整流程，全程无需第三方软件
- 动态扩展 + 弹出即隐藏的组合，兼顾了存储效率与隐私，赶紧试试吧！🤪
