# windows 专业版自带的 VHDX + BitLocker 加密你的学习资料

## 前言

- 有时候，我们需要加密我们的学习资料，以防止被他人访问。但是当文件太大时，压缩和解压会很耗时。而我们又不想去下载第三方软件，这个时候可以考虑使用 windows 专业版自带的 VHDX + BitLocker 加密你的学习资料。

## 第一步：创建 VHD/VHDX 文件

- 使用快捷键 `Win + R` 打开运行对话框，输入 `diskmgmt.msc`，打开磁盘管理工具。
- 点击菜单栏的 `操作`，选择 `创建 VHD`。（小注意：如果是置灰的，先点击下面的空白区域，再去点击 `创建 VHD`。）

图0

- 填写信息，点击 `确定`。
  - 位置：选择你电脑的位置。（注意`.vhdx`文件是他要帮你创建的，不用真实自己创建），例如: `D:\Mine\VHDX\学习资料.vhdx`
  - 虚拟硬盘大小：根据你的需求选择，例如我的学习资料需要大小为: 10TB，一般选择 `10GB` 应该够用了。
  - 虚拟硬盘格式：选择 `VHDX` 格式。（注意下：这里的格式要和前面文件的后缀对应上）
  - 虚拟硬盘类型：
    - 动态扩展：创建快，占空间随文件慢慢涨（**推荐**，快就完了）
    - 固定大小：创建慢，一次性占满全部设定容量，读写更稳

## 第二步：初始化磁盘，创建简单卷

- 初始化磁盘, 右击磁盘1, 选择 `初始化磁盘`。

## 第三步：启用 BitLocker 加密

- 打开资源管理器，选择此电脑，右击新加的简单卷，选择 `启用 BitLocker`。

图6

- 选择 `使用密码解锁驱动器`，选择保存到文件，一直点击 `下一步` 即可。

## 测试

- 禁止别人看：把他当作 U 盘，右击新加卷，选择 `弹出`，这样别人就看不到了。
- 自己看：双击之前的 `学习资料.vhdx` 文件，输入密码即可。
- 恢复：弹出之后，删除 `学习资料.vhdx` 文件即可。

## 总结

- 这样就可以加密你的学习资料，防止被他人访问。
- 赶紧去试吧，看效果如何。
